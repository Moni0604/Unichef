# UniChef Charity Landing Page

A premium, light-theme charity landing page built with React + Vite.

## Features
- Responsive desktop/tablet/mobile layout
- Premium humanitarian visual direction
- Hero, mission, impact, stories, trust, FAQ and CTA sections
- One-time / monthly donation UI
- Donation modal with amount selection
- Smooth scrolling
- Framer Motion animations
- Mobile navigation
- No backend required

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Notes
The donation experience is frontend-only. The Continue to donate button is ready to connect to a real payment gateway/backend later.

Photography is loaded from Unsplash URLs so the project stays lightweight.
